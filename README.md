# Кастомные наборы музыки для кс 2

Этот проект позволит играть с своими наборами музыки для CS 2. Сразу отвечу на вопрос: банят ли за это? Нет, проект полностью основан на интеграции с CS2.
Пока что проект находится в состоянии глобального тестирования. Но если вы хотите что-то предложить или захотите сделать слияние, то с радостью это делаете, это очень поможет проекту.

# Все готово, но что дальше

Дальше вы можете добавить свою музыку перейдя во вкладку с музыкальными наборами и нажать на кнопку создать/модифиц. набор музыки. Важное уточнение, для корректной работы необходимы звуковые файлы в формате .wav

<img width="350" height="332" alt="Снимок экрана 2026-08-07 200427" src="https://github.com/user-attachments/assets/82d1d106-9161-4779-84e6-5553802d444b" />

Но если вы захотите загрузить готовый набор музыки, то выбираете загрузить набор музыки, а далее просто заходите в нужную папку и нажимаете выбрать папку.
